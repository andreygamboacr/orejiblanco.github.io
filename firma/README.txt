IMPORTANTE:
Los HTML usan recursos publicados en:
https://orejiblanco.com/firma/assets/

Antes de usar las firmas en Gmail, sube la carpeta assets a tu repositorio de GitHub respetando esa ruta.
Luego abre el HTML en el navegador, selecciona la firma renderizada y copia/pega la firma en Gmail > Configuración > Ver todos los ajustes > General > Firma.

La fuente se declara como Lato con Arial como respaldo. Gmail puede sustituir Lato si no está disponible en el editor o en el dispositivo.
